Mushteri Analizi 

Bu Power BI layihəsi müştəri davranışlarını təhlil etmək və satış məlumatlarını vizuallaşdırmaq üçün hazırlanmışdır. Layihədə müştərilər "Çıxmış", "Yeni" və "Daimi" kateqoriyalarına bölünərək, müxtəlif zaman aralıqlarında satış statistikaları və regional analizlər təqdim olunur.

İstifadə olunan texnologiyalar
Power BI (Data təhlili və vizuallaşdırma)

DAX düsturları (Dinamik hesablamalar üçün)

Data təmizləmə və model qurma

Əsas Metrikalar
Müştəri sinifləndirməsi (85 gündən çox satış olmayanlar "Çıxmış", son 20 gündə satış edənlər "Yeni")
Regional satış analizləri
Zaman aralıqları üzrə satış dinamikası (3 rüb əvvəl, 10 ay əvvəl, son 5 ay)
Çatdırılma müddəti analizi (Ən tez çatdırılan 10 məhsul)

Proje Quruluşu
Data: "Satış" qovluğundan gələn məlumatlar

DAX ölçmələri: Müştəri sayı, satış cəmi, tarix filtrləri

Vizuallar: Qrafiklər, cədvəllər, kartlar

Nəticə
Layihə vasitəsilə şirkət:
Müştəri itkisini aşkar edə bilər
Yeni və daimi müştərilərin satış trendlərini müqayisə edə bilər
Region və zaman üzrə dəqiq təhlillər aparmaq üçün interaktiv dashboarddan istifadə edə bilər

Qeyd: Bütün hesablamalar DAX düsturları ilə dinamik şəkildə aparılmışdır. Dashboard istifadəçi dostu interfeysə malikdir.

Ətraflı məlumat üçün: Dokumentasiya faylına baxın
